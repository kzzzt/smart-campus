# 智慧校园管理与安全平台

> 湛卢·智能体与原生IDE应用开发大赛 —— 智慧校园管理与安全（体现“可落地”）
> 核心逻辑：为学校管理层减负，提高校园运营效率。

## 项目简介

本项目是一套面向智慧校园场景的可落地管理平台初稿，围绕“为学校管理层减负、提高校园运营效率”这一核心逻辑，包含三大子系统：

1. **AI 教务智能客服（AI 辅导员）**：7×24 小时解答学生关于请假、奖学金评定、学籍异动等问题；遇到 AI 无法处理的复杂情况自动生成工单并流转给对应的辅导员。
2. **校园能耗与安全智能预警系统**：结合物联网数据与智算视觉模型，分析宿舍违规电器使用、实验室安全隐患，预测教学楼用电高峰，实现节能减排。
3. **智能排课与教室调度系统**：利用 AI 算法（遗传算法 + 大模型约束条件理解）解决复杂排课冲突，并根据课程类型智能分配最合适的教室（如需电脑的课排机房）。

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 方式一：运行三系统串联演示（命令行版）
python run_demo.py

# 方式二：运行 Web 版（可交互界面 + 数据库持久化）
python run_web.py
# 浏览器打开 http://127.0.0.1:5000
```

> 说明：Web 版（Flask + SQLite）将三大子系统整合为可交互应用——**管理登录（演示账号 admin/SmartCampus@2026）保护三大功能页与写操作 API，含 CSRF 防护**；AI 客服问答、工单流转、能耗告警（IoT 功率 + 智算视觉双通道）、用电高峰预测、排课求解均在页面操作，数据持久化到 SQLite 且每次运行独立 `run_id`。模型层用大模型分层接入（`src/ai_service/llm.py`）：配置 `LLM_API_KEY` 即真实调用 OpenAI 兼容 API，未配置/断网/超时自动降级回本地规则引擎，离线可跑。遗传算法、能耗预测、工单流转为核心可运行逻辑。

## 亮点（创新性）

- **客服自动化 + 工单闭环**：AI 无法处理 → 自动生成工单 → 按类型流转给对应辅导员，形成“人机协同”闭环，而非单纯的问答机器人。
- **违规电器识别（视觉 + IoT）**：IoT 功率监测 + 智算视觉模型（图像识别违规电器）双通道判定，命中升级高置信告警，降低误报。
- **用电高峰预测 + 节能减排**：基于历史时序预测教学楼用电高峰，用于削峰调度。
- **遗传算法 + 大模型约束理解**：把自然语言排课需求（如“这周多开两节实验课”）解析为约束，交给遗传算法求解，兼顾鲁棒性与灵活性。
